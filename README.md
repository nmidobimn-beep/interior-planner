# Interior Planner

가정용 2D 인테리어/가구 배치 프로그램. 실제 집 치수(mm)를 입력하고, 벽·문·창문·콘센트를 표시한 뒤
실제 가구 크기를 입력해 자유롭게 배치·검토할 수 있는 것을 목표로 한다.

**가장 중요한 원칙:** 실제 치수와 화면 표시 비율은 항상 일치해야 한다. 모든 객체는 mm 단위로 저장하고,
화면 확대/축소는 뷰포트(카메라)만 바꾸며 객체의 실제 크기 데이터는 절대 변경하지 않는다.

## 기술 스택

- Vite + React + TypeScript
- 렌더링: HTML5 Canvas 2D (SVG 대신 선택 — 향후 수십~수백 개 객체를 다룰 때 픽셀 단위 제어와 성능이 더 유리함)

## 실행

```bash
npm install
npm run dev
```

## 배포

GitHub Pages로 배포한다. `master`에 push되면 `.github/workflows/deploy.yml`이 자동으로
빌드 후 배포한다(`actions/upload-pages-artifact` + `actions/deploy-pages`). 프로젝트
사이트(`https://<계정>.github.io/interior-planner/`)로 서빙되므로 `vite.config.ts`에
`base: '/interior-planner/'`를 지정해 에셋 경로를 맞췄다 — 로컬 `npm run dev`로 열 때도
`http://localhost:5173/interior-planner/`(포트는 다를 수 있음)로 접속해야 한다(루트 경로는
이 경로로 리다이렉트됨).

저장소의 Settings → Pages → Build and deployment → Source가 **GitHub Actions**로 되어
있어야 한다(리포지토리를 새로 만든 뒤 처음 한 번은 수동으로 확인/설정이 필요할 수 있음).

## 구조

```
src/
  types/geometry.ts   # Point/Size/Bounds 등 mm 기반 좌표 타입
  config/constants.ts # 줌 배율, 격자 간격, 색상 등 중앙 설정 (매직 넘버 금지)
  core/               # 순수 함수: 좌표 변환, 격자/눈금자, 벽·가구 기하/렌더링/스냅/히트테스트
  state/               # reducer 기반 도면 상태 (walls, furniture, 선택 객체)
  hooks/               # React 상태 훅 (뷰포트, 도면 상태, 캔버스 조작 총괄)
  components/          # 렌더링/이벤트 위임만 담당하는 UI 컴포넌트
```

비즈니스 로직(좌표 변환, 격자 간격 계산 등)은 `core/`에 순수 함수로 두고, 컴포넌트는 그 결과를 그리거나
이벤트를 위임하는 역할만 한다.

## 진행 단계

- [x] **1단계 — 기본 캔버스**: mm 좌표계, 마우스 휠 확대/축소(커서 중심), 드래그 화면 이동, 전체보기(Fit).
      격자·눈금자와 예시 도면(툴바의 "예시 표시" 체크박스)으로 비율이 정확한지 확인 가능.
- [x] **2단계 — 벽 작성**: 클릭-클릭 체인으로 벽 생성(연속 벽 바로 이어 그리기), 벽마다 두께(mm) 설정
      (기본값은 왼쪽 도구 패널에서, 개별 벽은 선택 후 오른쪽 속성 패널에서), 길이 직접 입력 수정,
      벽 본체 드래그로 이동 / 끝점 드래그로 리사이즈, 삭제. **스냅**: 기존 벽 끝점에 붙기(최우선, 방과
      방을 정확히 이어줌) → 0/45/90°... 각도 스냅 → mm 격자 스냅 순으로 적용되며, 툴바에서 on/off 가능.
      비정형 각도(스냅 허용오차 밖)는 자유롭게 그대로 그려진다.
- [x] **3단계 — 가구 도형**: 사각형/원형/ㄱ자형 가구를 클릭 한 번으로 배치(기본 크기로 놓인 뒤
      자동으로 선택 도구로 전환). 실제 가로/세로(원은 지름) mm 입력 시 축척에 맞춰 크기 반영,
      이름/메모 편집, 드래그 이동(격자 스냅), 회전 손잡이 드래그로 자유 회전(0/45/90°... 각도
      스냅 지원) + 숫자 직접 입력, 삭제. ㄱ자형은 바운딩박스 기준 팔 두께(mm)를 따로 설정하며,
      실제 도형 모양(노치 제외)으로 정확히 클릭 판정된다.
- [x] **4단계 — 문/창문/콘센트**: 문·창문은 벽에 종속(벽 위 offset+폭으로 저장, 벽 삭제 시 함께
      삭제). 벽을 클릭하면 그 위치에 기본 폭으로 배치, 자동으로 선택 도구 전환. 문은 벽에 배경색으로
      개구부를 내고 경첩(왼쪽/오른쪽)·여닫이(안쪽/바깥쪽) 방향에 따라 스윙 호(arc)를 그려 가구가
      개폐 공간을 침범하는지 확인 가능. 창문은 벽과 구분되는 색으로 표시. 콘센트는 벽과 무관하게
      자유 배치, 개수·메모 입력. 선택 도구에서 문/창문은 벽을 따라서만 드래그 이동(폭 변경 시
      중심 유지), 콘센트는 자유 이동(격자 스냅). 폭 변경 시 벽 길이를 넘지 않도록 자동 보정.
- [x] **5단계 — 복사/붙여넣기 / Undo·Redo**: 범용 히스토리 래퍼(core/../state/history.ts)로 모든
      데이터 변경 액션(선택 변경 제외)을 Undo/Redo. 벽/가구/문/창문/콘센트 모두 선택 후
      Ctrl+C·Ctrl+V(또는 툴바 버튼)로 복사/붙여넣기 — 연속 붙여넣기 시 원본이 아니라 방금
      붙여넣은 위치 기준으로 이어서 어긋나게 놓여 겹치지 않고 대각선으로 흩어진다. 툴바에
      실행취소/다시실행/복사/붙여넣기 버튼(사용 불가 시 비활성화) 추가. 단축키는 캔버스에
      포커스가 있을 때만 동작(속성 패널 입력 중에는 브라우저 기본 동작 유지).
- [x] **6단계 — 레이어 시스템**: 모든 객체(벽/가구/문/창문/콘센트)는 layerId를 가지며, 새로 만드는
      객체는 항상 "활성 레이어"(오른쪽 레이어 목록에서 클릭해 전환)에 들어간다. 레이어 추가/이름
      변경/눈 아이콘으로 표시·숨김(숨긴 레이어는 렌더링과 클릭 선택 모두에서 제외)/삭제(마지막 1개는
      삭제 불가, 삭제 시 그 안의 객체는 사라지지 않고 남은 첫 레이어로 자동 이동). 속성 패널에
      "레이어" 드롭다운으로 개별 객체를 다른 레이어로 옮길 수 있음. 전체보기는 보이는 레이어
      기준으로 계산.
- [x] **7단계 — 동선 표시**: "동선" 도구로 클릭-클릭 두 번이면 시작→끝 화살표 하나가 만들어진다
      (벽/문/창문과 별도의 객체). 화살표 표시 여부 토글, 메모, 레이어 이동, 선택 후 끝점 드래그로
      재조정 또는 몸통 드래그로 전체 이동, 삭제. 벽 끝점에 스냅되어 문/현관 위치에 정확히 붙일 수
      있음.
- [x] **8단계 — 저장 및 불러오기**: 저장은 현재 도면 전체(벽/가구/문/창문/콘센트/동선/레이어)를
      버전이 붙은 JSON 파일로 내려받는다. 불러오기는 JSON 파일을 선택하면 형태를 검증한 뒤
      (레이어가 없어졌으면 첫 레이어로 안전하게 재배정) 도면을 통째로 교체하고 실행취소 기록도
      새로 시작한다. 새로 만들기는 확인 후 빈 도면으로 초기화. 추가로 편집이 멈추면 0.5초 뒤
      브라우저 localStorage에 자동 저장해, 새로고침해도 마지막 작업이 그대로 복원된다(저장하지
      않고 나가도 안전). **주의**: 이 저장/불러오기는 실제 파일 다운로드·업로드를 쓰므로 미리보기
      아티팩트(샌드박스) 안에서는 동작하지 않고, `npm run dev`로 직접 실행하는 실제 앱에서 정상
      동작한다(Playwright로 실제 dev 서버에 대해 검증함).

각 단계는 이전 단계가 정상 동작함을 확인한 뒤에만 진행한다.

## 추가 기능

- **벽 길이 스냅**: 벽을 그릴 때(체인 드로잉) 각도는 그대로 두고 길이만 설정한 단위(100mm~1000mm,
  기본 100mm, 벽 도구 선택 시 왼쪽 패널에서 설정)의 배수로 반올림해서 그려진다. 다른 벽 끝점에
  붙는 스냅(최우선)이 걸린 경우는 길이 스냅을 적용하지 않아 정확한 연결을 해치지 않는다.
- **표시 단위 전환(mm/cm/m)**: 툴바의 "단위" 버튼으로 순환 전환. 내부 저장은 항상 mm로 고정되고,
  눈금자·상태바 커서 위치·벽 그리기 중 길이 표시·속성 패널의 모든 길이 입력란(벽 길이/두께,
  가구 크기, 문/창문 폭)의 "표시"만 바뀐다. 축척 안내(1px = X.XXmm)는 좌표계 자체를 설명하는
  값이라 mm로 고정.

## Undo/Redo 기록 방식 (드래그 배치 처리)

이동·회전·리사이즈처럼 드래그 한 번에 마우스 이동 이벤트가 수십 번 발생하는 작업은, 그 중간
과정을 History에 쌓지 않고 **드래그 시작 상태 → 드래그 종료 상태**를 통째로 한 건으로 기록한다.
드래그 도중에는 `update*(..., transient=true)`로 화면만 갱신하고(History 제외), 드래그가
끝나면 실제로 값이 바뀐 경우에만 `commitTransientEdit()`으로 시작 시점 스냅샷을 History에
등록한다(`state/history.ts`의 `commit()`). 값이 하나도 안 바뀌었으면(클릭만 하고 끝난 경우 등)
아무 기록도 남기지 않는다. 벽 이동/리사이즈, 가구 이동/회전, 문/창문/콘센트 이동, 동선
이동/끝점/곡선 조절점 드래그 모두 동일하게 적용된다. Ctrl+Z 한 번으로 드래그 전체가 즉시
되돌아간다.

## 동선 곡선(베지어)

동선 도구에서 "직선"/"곡선"을 선택할 수 있다. 곡선은 2차 베지어(제어점 1개)로 표현하며,
시작점·끝점·제어점을 각각 독립적으로 드래그해 모양을 조절한다. 화살표 머리는 곡선 끝에서의
실제 진행 방향(제어점→끝점 방향)을 따라 회전한다. 속성 패널의 "곡선으로 표시" 체크박스로
기존 동선을 직선⇄곡선으로 전환할 수 있다(곡선으로 켜면 자동으로 기본 제어점이 생성됨).

## 스냅 대상 확장 + 개별 on/off

기존에는 벽 끝점만 스냅 대상이었으나, 이제 **끝점(벽/문/창문 구간 끝/콘센트/동선 시작·끝)·
중심점(가구 중심)·모서리(가구의 회전된 바운딩 도형 꼭짓점)** 세 카테고리를 모두 스냅 후보로
인식하고, 툴바에서 각각 개별로 켜고 끌 수 있다(스냅이 켜져 있을 때만 표시). 예: 가구를 다른
가구의 모서리에 정확히 맞춰 놓을 수 있다.

**참고**: 요청에 있었던 "가상선(정렬 가이드 트래킹)" — 마우스 이동 중 다른 객체와 정렬될 때
자동으로 안내선을 표시하는 기능 — 은 이번에 포함하지 않았다. 이건 지금의 스냅과는 성격이 다른
훨씬 큰 기능(실시간으로 모든 객체와의 정렬 관계를 계산해 임시 가이드선을 그려야 함)이라 별도
작업으로 진행하는 게 맞다고 판단했다. 필요하면 말씀해달라.

## 텍스트 라벨

방 이름 등을 도면 위에 직접 표시하는 간단한 텍스트 객체. "텍스트" 도구로 클릭 한 번이면 기본
문구("텍스트")로 놓이고 자동으로 선택 도구로 전환된다. 속성 패널에서 내용을 바로 수정할 수
있고, 드래그로 이동(스냅 지원)·레이어 이동·삭제가 가능하다. 다른 객체와 동일하게 드래그는
Undo 한 건으로 묶이고, 복사/붙여넣기도 지원한다. 글자 크기는 확대/축소와 무관하게 항상 같은
화면 픽셀 크기로 표시된다(가구 이름표와 동일한 방식).

## 예시 표시 — C타입 3Bay 판상형 아파트 예제 도면

`core/demoScene.ts`. 툴바의 "예시 표시" 체크박스(기본 켜짐)를 켜면 처음 방 4000×3000mm +
침대 2000×1000mm짜리 단순 사각형 대신, 사용자가 제공한 실제 아파트 평면도 이미지를
**픽셀 단위로 직접 분석**해(방 배치·문 위치·통로 구조를 원본 이미지에서 좌표를 추출) 옮겨
그린 예제 도면이 보인다 — 거실(3.7m×3.7m)·안방(3.4m×3.4m)·작은방 1(2.7m×3.0m)·작은방
2(2.4m×3.0m)·주방/식당(2.5m×3.0m)·공용 욕실(1.7m×2.1m)·욕실B·드레스룸·발코니 2개, 문
8개·창문 9개·방 이름 라벨 11개로 구성된다(치수는 사용자가 알려준 대략적인 범위를 적용).
실제 편집 데이터(벽/문/창문/라벨)와 완전히 동일한 렌더링 함수(`drawWalls`/`drawDoors`/
`drawWindows`/`drawLabels`)로 그려서 "이 앱으로 완성하면 이런 모습이 된다"를 그대로 보여주며,
선택·편집은 되지 않는 참고용 오버레이다(실제 저장 데이터에는 포함되지 않음).

원본 이미지에서 실제로 확인한, 이전 버전(간단한 직사각형 + 모서리 노치 하나)에서 놓쳤던
핵심 구조:
- 건물 왼쪽은 위→아래로 갈수록 넓어지는 **3단 계단식 외곽선**이다(발코니1·욕실A 열이 가장
  안쪽, 현관이 한 단 더 밖으로, 작은방 열이 가장 바깥쪽).
- 현관은 독립된 작은 방이며, 세대 현관문은 이 계단식 단차 부분(공용 계단실과 맞닿는 바깥쪽
  외벽)에 있다 — 현관과 욕실A 사이, 현관 위쪽은 세대 밖(공용 계단실로 추정)이라 벽을 그리지
  않는다.
- 발코니는 2개뿐이다(발코니1, 안방 발코니) — 드레스룸 옆에는 발코니가 없다.
- 욕실A는 현관이 아니라 **거실 쪽**으로 문이 나 있다. 현관 자체는 거실과 벽 없이 바로
  이어진다("현관+복도"를 하나의 방으로 합쳤던 이전 버전과 다름).
- 주방/식당도 거실과 벽 없이 열려 있다(오픈플랜).
- 안방은 거실과 **딱 한 곳**(스핀 월의 문 하나)으로만 연결된다 — 이전 버전엔 있던 "현관↔안방"
  별도 문은 실제 이미지에 없다.
- 드레스룸은 문 없이 안방에 바로 열려 있다(붙박이형).
- 작은방 두 개 모두 "복도 쪽" 벽에 문이 있다 — 거실 쪽 벽은 막혀 있다(이전 버전은 반대로
  그려져 있었음).

## 다중 선택 (1단계)

가구·콘센트·동선·라벨을 대상으로 다중 선택을 지원한다. 벽/문/창문은 기존 단일 선택 구조를
그대로 유지하고 이번 단계에는 포함하지 않았다(구조 객체 다중 선택은 별도 검토가 필요해 보류).

- **Shift+클릭**: 클릭한 객체를 선택 목록에 추가/제거(토글) 한다.
- **영역 드래그 선택**: 빈 캔버스에서 드래그하면 마퀴(marquee) 사각형이 표시된다. **왼쪽→오른쪽**
  드래그는 완전히 포함된 객체만, **오른쪽→왼쪽** 드래그는 영역에 닿기만 해도 선택한다(마퀴가
  점선/실선으로 구분되어 표시됨). 화면 이동은 이제 가운데 버튼(휠) 드래그로 한다 — 왼쪽 버튼
  빈 캔버스 드래그는 영역 선택으로 바뀌었다(CAD/디자인 툴의 일반적인 관례).
- **그룹 이동**: 다중 선택된 객체 중 하나를 드래그하면 전체가 서로의 상대 위치를 유지한 채
  함께 이동한다. 그룹의 바운딩 박스 모서리 4개+중심을 스냅 후보 지점으로 써서 벽 끝점 등에
  붙일 수 있다.
- **그룹 회전**: 다중 선택 시 바운딩 박스 위에 표시되는 손잡이를 드래그하면, 바운딩 박스
  중심을 기준으로 전체가 함께 회전한다(가구는 자신의 회전값도 함께 갱신됨).
- **다중 선택 삭제**: Delete/Backspace 또는 속성 패널의 "선택한 N개 삭제" 버튼으로 한 번에
  삭제한다.
- **Undo 배치**: 몇 개를 선택했든 그룹 이동/회전/삭제는 항상 Undo 기록 한 건이다(기존 트랜지언트
  드래그 커밋 방식을 그대로 재사용).
- 다중 선택 중에는 개별 손잡이(회전/끝점 등) 대신 공용 바운딩 박스 + 그룹 회전 손잡이만
  보여준다. 클릭만 하고 드래그하지 않으면(실수로 살짝 움직인 경우 포함) 클릭한 객체 하나만
  남도록 자동으로 정리된다(표준적인 선택 도구 동작).
- 복사/붙여넣기는 아직 단일 객체만 지원한다(다중 선택 복사/붙여넣기는 다음 단계 후보).

## 다중 기준점 스냅 (2단계)

기존엔 이동 중인 객체의 기준점 하나(가구는 중심, 벽/동선은 시작점)만 스냅 대상이었다. 이제
**이동 대상 객체 자체의 여러 기준점**과 **주변 객체의 여러 기준점**을 모두 비교해 가장 가까운
조합에 맞춘다 — "마우스로 잡은 위치"와 "스냅되는 기준점"은 서로 다를 수 있다(예: 가구 중심을
잡고 드래그해도, 그 가구의 모서리가 벽 끝점에 가까워지면 모서리가 거기 스냅된다).

- **가구(사각형/ㄱ자)**: 중심 + 모서리 4개 + 변 중간점 4개, 총 9개 기준점. **원형**: 중심 +
  상하좌우 4개 지점.
- **벽/동선(직선)**: 시작점·끝점·중간점.
- **동선(곡선)**: 시작점·끝점·곡선 조절점·곡선 중간 대표점(t=0.5 지점).
- **스냅 대상(후보) 쪽**도 함께 확장: 기존엔 벽 끝점만 후보였는데, 이제 벽 시작·끝·중간점,
  동선 시작·끝·중간·조절점, 라벨 위치(라벨은 이번에 처음 후보로 추가됨), 가구 중심/모서리/변
  중간점을 모두 후보로 쓴다(스냅 카테고리 켜고 끄기는 기존 그대로 끝점/중심점/모서리 3종).
- 후보에 걸리는 게 없으면 기존처럼 mm 격자에 맞춘다(항상 어떤 형태로든 스냅되는 감각 유지).
- 다중 선택 그룹 이동은 성능을 고려해 우선 그룹 전체의 바운딩 박스 기준점(모서리4+중심)만
  사용한다 — 개별 객체 기준점까지 확장은 필요성이 확인되면 다음 단계에서.
- Playwright로 검증: 가구의 "중심"을 마우스로 잡고 드래그해도 그 가구의 "왼쪽-중앙 모서리"가
  벽 끝점에 정확히 스냅됨(마우스 위치와 스냅 기준 분리)을 확인, 기존 회귀 테스트 전부 통과.

## 자유 다각형 (3단계)

사각형/원형/ㄱ자형 외에 사용자가 원하는 형태를 그릴 수 있는 자유 다각형 도구를 추가했다.

- **그리기**: "다각형" 도구에서 클릭할 때마다 꼭짓점이 추가된다. 꼭짓점이 3개 이상일 때 첫
  꼭짓점 근처를 다시 클릭하거나 Enter를 누르면 도형이 완성된다. Esc 또는 우클릭으로 그리는
  중인 다각형을 취소할 수 있다. 왼쪽 도구 패널에 지금까지 찍은 꼭짓점 수를 표시한다.
- **수정**: 선택 후 각 꼭짓점(손잡이로 표시)을 드래그해 모양을 바꿀 수 있다(스냅 지원). 꼭짓점
  추가/삭제는 이번 단계엔 포함하지 않았다(요청에 "필요하면"이라 명시되어 있어 우선 보류).
- **이동/회전**: 선택 후 본체를 드래그하면 전체가 평행 이동한다(모든 꼭짓점 + 변 중간점 +
  중심을 스냅 후보로 검사). 다각형 하나만 선택해도 가구처럼 회전 손잡이(바운딩 박스 위,
  다중 선택 때와 동일한 손잡이)가 나타나 중심을 기준으로 회전할 수 있다 — 내부적으로
  rotationDeg 필드 없이 모든 꼭짓점을 직접 회전시키는 방식이라 동선의 시작/끝점과 같은 접근이다.
- **기존 기능과 동일하게 지원**: 선택, 다중 선택(가구·콘센트·동선·라벨과 함께 Shift+클릭/영역
  선택 가능), 복사/붙여넣기, 삭제, 레이어 이동, 이름·색상·메모 편집, Undo/Redo(드래그 한 번 =
  기록 한 건), 스냅.
- Playwright로 검증: 삼각형 생성/이름 편집/전체 이동(Undo 1건)/꼭짓점 드래그로 재형성(Undo
  1건)/Esc 취소/삭제/가구와의 다중 선택 참여까지 전부 확인, 기존 회귀 테스트 전부 재통과,
  콘솔 에러 없음.

## 가구 라이브러리 (4단계)

자주 쓰는 가구/다각형을 저장해두고 다른 도면(다른 프로젝트)에서도 다시 불러 쓸 수 있는
라이브러리 기능을 추가했다.

- **저장**: 가구 또는 다각형을 선택하면 속성 패널에 "+ 가구로 저장" 버튼이 나타난다. 이름과
  분류(예: 침실/거실/주방, 비워두면 "기타")를 물어본 뒤 저장한다. 저장되는 정보: 이름, 종류
  (가구/다각형), 도형 종류, 가로/세로(또는 다각형 좌표 — 중심 기준 상대 좌표로 정규화해 저장),
  ㄱ자 팔 두께, 기본 회전값, 색상, 메모. **현재 평면도 위의 x/y 위치는 저장하지 않는다**(요청
  그대로) — 그래서 어디서 불러오든 새 위치에 놓인다.
  - 저장은 원본 도면(`interior-planner:autosave`)과 **별도의 localStorage 키**
    (`interior-planner:furniture-library`)에 보관되어, "새로 만들기"·다른 도면 불러오기와
    무관하게 계속 남아있고 다음 프로젝트에서도 그대로 쓸 수 있다(Playwright로 "새로 만들기"
    전후 라이브러리 항목 수가 그대로임을 확인).
- **불러오기**: 왼쪽 도구 패널 아래 "가구 라이브러리" 패널에서 분류별로 묶어 보여준다. 항목을
  클릭하면 화면 왼쪽 위 근처에 **새로운 독립 객체**로 추가된다 — 원본(라이브러리 항목)과
  전혀 연결되지 않으므로, 평면도에 놓인 뒤 크기·이름·색을 바꿔도 라이브러리의 원본은 그대로다
  (반대도 마찬가지 — 평면도의 원본 객체를 나중에 바꿔도 이미 저장해둔 라이브러리 항목은
  안 바뀐다). 항목 오른쪽의 "×"로 라이브러리에서 삭제할 수 있다.
- 이름/분류 입력은 우선 `window.prompt` 기반의 간단한 방식으로 구현했다(모달 UI는 다음 단계
  후보). 드래그해서 캔버스에 놓는 방식은 이번엔 클릭 배치로 대체했다(요청에 "클릭 또는
  드래그"라 명시되어 있어 클릭만 우선 구현).
- Playwright로 검증: 가구 저장(이름/분류 프롬프트) → 라이브러리에 분류별로 표시 → 원본을
  수정해도 라이브러리 항목은 그대로 → 라이브러리에서 불러오면 저장 당시 크기/이름 그대로 새
  객체 생성 → 다각형 저장도 동일하게 동작 → 삭제 → "새로 만들기" 후에도 라이브러리 유지, 모두
  확인. 콘솔 에러 없음, 기존 회귀 테스트 전부 재통과.

## 치수선(길이 제도선) (5단계)

두 점 사이의 실제 거리를 도면 위에 직접 표시하는 치수선(dimension line) 도구를 추가했다.
건축 도면에서 흔히 쓰는 방식대로, 측정 대상 점에서 치수선까지 이어지는 보조선(연장선)과
양 끝 눈금, 거리 텍스트를 함께 그린다.

- **그리기**: "치수선" 도구에서 첫 점을 클릭하고 두 번째 점을 클릭하면 완성된다(벽/동선과
  동일한 클릭-클릭 방식). 생성 직후 자동으로 선택 도구로 전환된다.
- **3가지 표시 방식 중 하나를 선택**(왼쪽 도구 패널의 직선거리/가로거리/세로거리 버튼, 도구를
  쓰기 전과 기존 치수선 선택 후 속성 패널의 드롭다운 양쪽에서 바꿀 수 있음):
  - **직선거리**: 두 점을 잇는 실제 직선 거리(√(dx²+dy²))를 그 선 위에 그대로 표시한다.
  - **가로거리**: 두 점의 x축 거리만 표시한다. 치수선은 두 점보다 300mm 아래로 띄워서
    수평으로 그리고, 각 점에서 치수선까지 점선 보조선을 내린다.
  - **세로거리**: 두 점의 y축 거리만 표시한다(가로거리와 대칭 — 300mm 오른쪽으로 띄워 수직
    으로 그림).
  - 세 방식 모두 저장 시에는 시작점·끝점·모드만 저장하고, 보조선/오프셋 위치는 그릴 때마다
    다시 계산한다(불필요한 좌표를 저장하지 않기 위함).
- **기존 기능과 동일하게 지원**: 선택, 다중 선택(가구·콘센트·동선·라벨·다각형과 함께
  Shift+클릭/영역 선택 가능, 그룹 이동/회전에도 참여), 끝점 드래그로 재조정 또는 몸통 드래그로
  전체 이동(둘 다 다른 객체의 기준점에 스냅), 복사/붙여넣기, 삭제, 레이어 이동, 메모 편집,
  Undo/Redo(드래그 한 번 = 기록 한 건). 표시 단위(mm/cm/m) 전환도 동일하게 적용된다.
- Playwright로 검증: 직선/가로/세로 3가지 모드 각각 의도한 값으로 거리가 계산되는지(가로거리
  모드에서 세로 이동은 무시, 세로거리 모드에서 가로 이동은 무시 등), 속성 패널 드롭다운으로
  기존 치수선의 모드를 바꾸면 즉시 재계산되는지, 다중 선택 그룹 이동이 Undo 한 건으로 묶이는지,
  끝점 드래그로 길이가 재계산되는지, 복사/붙여넣기·삭제까지 모두 확인. 기존 회귀 테스트(벽/문/
  가구/동선/텍스트/다각형/레이어/Undo·Redo) 전부 재통과, 콘솔 에러 없음.

## CAD 커맨드 시스템 (6단계)

마우스로 툴바 버튼을 누르는 기존 방식에 더해, 전문 CAD 프로그램처럼 키보드 명령어로 주요
기능을 빠르게 실행할 수 있는 명령어 입력 체계를 추가했다. `명령어 입력 → Space(또는 Enter)
→ 실행`이 기본 흐름이며, 대소문자를 구분하지 않는다. 텍스트 입력창(가구 이름, 메모 등)에
포커스가 있을 때는 전역 명령어 캡처가 자동으로 꺼진다.

- **Command Registry**: `core/commandDefinitions.ts`에 명령어 하나당 `command`(대표
  코드)/`aliases`(별칭)/`name`/`description`/`category`/`repeatable`/`execute`를 갖는
  배열 하나로 전체 명령을 관리한다. 명령 실행·자동완성·도움말이 모두 이 배열 하나에서 파생되므로,
  새 명령을 추가하려면 배열에 항목 하나만 더하면 된다.
- **툴바와 완전히 같은 함수를 재사용**: 명령어로 도구를 켜는 것(`L`→벽, `B`→사각형 등)은
  내부적으로 툴바 버튼과 똑같이 `interaction.setActiveTool(...)`을 호출한다 — 별도 로직을
  중복 구현하지 않는다. 사용자가 명령 대신 툴바를 직접 눌러 도구를 바꿔도, 두 입력 방식의
  상태가 서로 어긋나지 않도록 자동으로 동기화된다.
- **기본 명령어**(그리기 — 모두 반복 배치 가능, Space/ESC로 종료): `L` 벽, `B` 사각형, `C`
  원, `EL` ㄱ자형, `MU` 다각형(작성 중에는 Space가 "명령 종료"가 아니라 "도형 완성"으로
  동작 — 완성 후 새 다각형을 계속 그릴 수 있음), `D` 문, `WIN` 창문, `CON` 콘센트, `SL` 동선,
  `T` 텍스트.
- **편집 명령어**: `M` 이동(기준점 클릭 → 이동할 위치 클릭), `R` 회전(기준각 지점 클릭 →
  목표 각도 지점 클릭, 선택 바운딩 박스 중심을 축으로 회전), `CO` 복사(기준점 → 붙여넣을 위치,
  원본은 그대로 두고 새 객체 생성), `DEL` 선택 삭제, `BL` 벽 합치기(아래 참고). 몇 개를
  선택했든 이동/회전/복사는 Undo 한 건으로 기록된다.
- **벽 합치기(BL)** — 모서리(꺾이는 지점)도 지원: 실행 후 병합할 벽을 순서대로 클릭하면
  (강조색으로 표시) 선택 목록에 더해지고, Space로 실행한다. 선택한 벽은 끝점끼리 이어진
  하나의 사슬이어야 한다(한 지점에 벽이 3개 이상 모이면 가지침으로 보고 거부). 그 사슬을
  일직선 구간별로 나눠서 처리한다:
  - **일직선으로 이어진 구간**(벽 2개 이상)은 기존처럼 벽 하나로 완전히 합쳐진다. 그 구간에
    있던 문/창문은 사라지지 않고 새 벽으로 옮겨지며, 위치(월드 좌표)는 그대로 유지되도록
    offset이 재계산된다.
  - **꺾이는 지점(모서리)**은 벽 개수를 줄이지 않는다 — 대신 두 벽이 정확히 같은 점에서
    만나도록 끝점만 정리한다("모서리 정리"). 이미 정확히 맞물려 있으면(스냅 켜고 그리면
    보통 이 경우) 데이터를 바꾸지 않고 "정리할 내용 없음"으로 조용히 성공 처리한다(에러
    아님). 일직선 구간과 모서리가 섞인 사슬(예: 벽 3개가 일직선으로 이어지다 마지막에 한 번
    꺾이는 경우)도 지원 — 일직선 구간은 합치고 꺾이는 지점만 정리한다.
  - 두 조건(사슬 연결 자체가 안 됨 등) 중 하나라도 실패하면 데이터를 바꾸지 않고 이유를
    명령창에 표시하며, 명령은 계속 활성 상태로 남아 선택을 다시 조정할 수 있다.
  - 몇 개의 구간을 합치고 몇 곳의 모서리를 정리했든 전체가 액션 하나이므로, Undo 한 번으로
    병합 전 상태(원래 벽 배치)로 완전히 복원된다.
- **시스템 명령어**: `SNAP` 스냅 ON/OFF 전환, `Z` 실행 취소, `RE` 다시 실행, `LA` 레이어
  패널로 스크롤 이동(짧게 강조 표시), `NL` 새 레이어 생성, `?` 명령어 도움말 열기. 이 명령들은
  명령창 로그에는 남지만 Undo 히스토리에는 남지 않는다(객체 데이터 변경이 아니므로).
- **최근 명령 반복**: 활성 명령/입력 버퍼가 모두 없는 상태에서 Space나 Enter만 누르면 마지막
  으로 실행한 "반복할 만한" 명령이 다시 실행된다(그리기 명령들이 대상 — SNAP/Undo/도움말처럼
  반복이 의미 없는 명령은 제외).
- **자동완성**: 명령어를 입력하는 동안 그 접두사로 시작하는 후보들을 명령창 아래에 보여준다
  (예: `S` 입력 시 `SL`/`SNAP`). 방향키(↑/↓)로 후보를 고르거나 마우스로 클릭해 바로 실행할
  수 있고, 정확히 일치하는 명령이 없으면(예: `S`만 입력하고 Space) 지금 하이라이트된 후보가
  대신 실행된다.
- **하단 명령창**: 화면 아래 CAD 스타일 명령창을 두었다. 평소엔 "⌃ 명령창" 한 줄로 접혀 있고
  클릭하면 펼쳐진다. 펼치면 최근 명령 로그, 지금 입력 중인 명령어, 활성 명령의 안내 문구("현재
  명령 : 벽 그리기 [L] — 시작점을 클릭하세요." 등)를 보여준다. 로그에는 마우스 이동 같은 중간
  과정은 남기지 않고, 사용자가 의미 있는 작업을 완료했을 때만 기록한다(Undo 개선과 같은 철학).
- **명령어 도움말**: 명령창의 "?" 버튼이나 `?` 명령으로 열리는 모달에 그리기/편집/시스템
  카테고리별로 전체 명령어 표를 보여주며, 검색창으로 필터링할 수 있다. 이 표도 Command
  Registry에서 그대로 가져오므로 새 명령을 추가하면 자동으로 반영된다.
- **기존 단축키 유지**: Ctrl+C/V(복사/붙여넣기), Ctrl+Z/Y(실행 취소/다시 실행), Delete(삭제),
  Esc(현재 작업 취소)는 그대로 동작한다. 새 명령어 체계는 이들과 별개의 입력 경로라 서로
  충돌하지 않는다.
- Playwright로 검증: 텍스트 입력 중 명령어가 캡처되지 않는지, `L`/`B` 명령의 반복 배치와
  Space/Esc 종료, 빈 명령창에서 Space로 마지막 명령이 재실행되는지, `SNAP`/`Z`/`RE`/`DEL`이
  버튼 클릭과 동일하게 동작하는지, `M`/`R`/`CO`가 각각 정확한 delta/각도로 적용되고 Undo
  한 건으로 되돌아가는지, `BL`이 일직선 성공(길이 합산, Undo 복원)·직각 모서리 성공(벽 개수
  유지, "일직선이 아니다" 에러 없음, 이미 맞물려 있으면 안내만 하고 데이터 불변)·실패(연결
  안 된 벽 — 에러 표시, 데이터 불변, 명령 유지) 모두 올바르게 동작하는지, `LA`/`NL`,
  자동완성 후보 표시, 도움말 모달 열기/검색/닫기까지 확인. 기존 회귀 테스트(벽/문/가구/동선/
  텍스트/다각형/치수선/레이어/Undo·Redo) 전부 재통과, 콘솔 에러 없음.
